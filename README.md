# Furniture-Sales-Analyst
## Project Background
This data about global e-ecommerce company that sells popular furniture products. 

Insight and recommendation are provided on the following key areas:
- Sales Trend Analysis : Ecalution of historical sales patterns, focusing on Revenue, Order Volume, and Average Order Value (AOV)
- Product Level Performance : An analysis various product lines, understanding the impact on sales and retturns
- Regional Comparisons : An evalution of sales and orders by region
